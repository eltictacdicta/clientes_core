# clientes_core

Plugin núcleo de terceros para [FSFramework](https://github.com/eltictacdicta/fs-framework).

Repositorio: https://github.com/eltictacdicta/clientes_core

## Qué incluye

- Clientes (`cliente`)
- Direcciones de clientes (`direccion_cliente`)
- Grupos de clientes y descuentos por grupo
- Controladores de administración de clientes
- Registro de hooks de vista (`ViewHookRegistry`, consumido por el core)

## Dependencias

No requiere otros plugins. Es base para:

- `clientes_facturacion`
- `clientes_catalogo`
- `facturacion_base`

## Instalación

```bash
git clone https://github.com/eltictacdicta/clientes_core.git plugins/clientes_core
```

O desde el panel: **Admin → Tienda de Plugins → Descargar**.
